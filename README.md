# ModbusKit · 多协议工业通讯调试台

一个可离线运行的工业通讯调试工具。把 **Modbus TCP、Modbus RTU、三菱 MC 3E、欧姆龙 FINS/TCP、AB Ethernet/IP CIP** 五个协议栈集成到同一界面，支持**模拟器 / 真机 TCP / 串口直连**三种模式，实时显示十六进制收发报文。**v1.2 新增 TCP 长连接复用与断线自动重连、报文字段级解码（点击查看每个字节含义）、异常码诊断助手（自动给出原因与排查步骤）。v1.3 补齐模拟器并发锁、批量操作进度/取消、字段一致性，并用 pymodbus 标准从站完成 13 项 API 端到端测试。**

> 适用：PLC/仪表通讯调试、协议学习、上位机联调、产线排障、教学演示。

> **在线体验**：[https://modbuskit-debug-console.app.workbuddy.host/?sharecode=OTWZEAO5QP](https://modbuskit-debug-console.app.workbuddy.host/?sharecode=OTWZEAO5QP)  
> 云端可直接体验模拟器模式与真机 TCP 模式；串口直连需下载 exe 在本地运行。

## 一、功能特性

| 特性 | 说明 |
|---|---|
| 五协议统一界面 | 5 种协议配置（Modbus TCP / Modbus RTU / 三菱 MC / 欧姆龙 FINS / AB EIP）一键切换 |
| 三模式 | **模拟器**：内置内存从站，读写状态保持，零硬件完整演示；**真机 TCP**：真实 socket 收发；**串口直连**：pyserial 走 COM 口 |
| 报文级可视 | 每次操作显示完整 TX/RX 十六进制报文、字节数、耗时、功能码 |
| 丰富功能码 | Modbus 8 个功能码、三菱 4 个指令、欧姆龙 DM/CIO 读写、AB Get/Set/List Identity |
| 状态持久 | 写操作即时更新模拟从站内存，后续读取可见（验证闭环） |
| 批量读取 | 按地址步进连续读取 N 个区间 |
| 历史记录 | 最近 200 条操作流水，可一键清空、导出 CSV/JSON、导入并**逐帧回放** |
| 从站扫描 | 1–247 并发探询，列出总线上所有应答设备（含异常帧识别） |
| 串口直连 | 自动枚举 COM 口，支持 9600–115200 波特率、校验位/停止位配置 |
| 异常演示 | 非法地址返回标准异常帧（0x83 + 异常码 0x02） |

## 二、快速开始

### 方式 A：在线体验（无需安装）
打开 [ModbusKit 在线调试台](https://modbuskit-debug-console.app.workbuddy.host/?sharecode=OTWZEAO5QP)，选择协议 → 功能码 → 填参数 → 点「执行操作」。云端支持模拟器模式与真机 TCP 模式；串口直连请使用本地 exe。

1. 双击 `dist\ModbusKit.exe`
2. 自动选空闲端口并打开浏览器，进入调试台
3. 选择协议 → 功能码 → 填参数 → 点「执行操作」

```bat

python server.py
:: 浏览器打开 http://127.0.0.1:8767
```

### 方式 D：一键重新打包 exe
```bat

```

## 三、双模式说明

### 模拟器模式（默认）
- 内置五协议栈内存从站：Modbus 保持/输入寄存器+线圈、三菱 D/M 软元件、欧姆龙 DM/CIO、AB 标签表
- 所有读写的报文**真实按协议规范编码**，经过完整的构造 → 从站解析 → 响应构造 → 解析链路
- 写操作会更新从站内存，读回可见，形成验证闭环
- 适合：无硬件调试、协议学习、代码验证、教学演示

### 真机 TCP 模式
- 切换到「真机 TCP」，填写设备 IP 与端口
- 点「测试连接」验证 TCP 可达，再执行读写
- **v1.2 长连接**：点「建立长连接」后，后续读写复用同一条 TCP 会话（避免反复握手导致 PLC 连接数耗尽）；每条操作显示 `长连接` 标识，左下角实时显示 TX 次数与重连次数。点「断开长连接」释放。若设备主动断链，工具会自动重连并重发一次
- 默认端口：Modbus TCP 502 / 三菱 MC 1031 / 欧姆龙 FINS 9600 / AB EIP 44818

### 报文字段级解码（v1.2 新增）
- 每条 TX/RX 报文的每个字节都可点击：高亮所属字段并显示**字段名、解析值、字节偏移、说明**
- 覆盖 MBAP/PDU、三菱 MC 3E 指令/软元件/地址、FINS 头/存储区/BCD 地址、EIP 封装头/CPF/CIP 路径等
- 「复制」按钮复制纯十六进制串，便于粘贴到工单或与其他工具对比

### 异常诊断助手（v1.2 新增）
- 操作失败时结果区自动弹出诊断卡片，分协议异常 / 网络 / 超时 / 配置 / 未知五类
- 给出**可能原因**与**分步排查建议**：如 Modbus 0x02 非法地址 → 核对地址范围、扫描在线从站；FINS 拒绝 → 检查节点号与存储区
- 支持 MC 结束码、CIP 状态、CRC 校验失败、连接被拒绝、设备无应答等常见故障

### 串口直连模式（v1.1 新增）
- 切换到「串口直连」自动切到 Modbus RTU；选择 COM 口、波特率、数据位、校验位、停止位
- 点「测试连接」开关一次端口预检；读写走真实 pyserial 收发，按 RTU 帧长智能读取完整响应
- 无硬件时切回「模拟器」仍可完整演示

### 从站 ID 扫描（v1.1 新增）
- Modbus TCP/RTU 协议下，填起止 ID 和超时，点「扫描总线」
- 真机模式用 12 线程并发探询 1–247，收到任意非空响应（含异常帧）即判定在线
- 模拟器模式内置虚拟从站 1/3/7/16/42，零硬件可演示

### 历史导出与回放（v1.1 新增）
- 「历史记录」标签下：导出 CSV（Excel 可直接打开）/ JSON，导入历史文件
- 点「回放」按时间顺序逐帧重现请求/响应报文，适合复盘与教学演示

### 批量进度与取消（v1.3 新增）
- 批量读取改为后台任务，界面实时显示 `进度 N/M`，可随时点「取消」
- 取消采用协作式：当前指令完成后停止，不会留下半写状态
- 批量历史与单条完全一致（都带字段解码与诊断），回放不会丢信息

### 并发安全（v1.3 新增）
- 模拟器状态由可重入锁保护，批量读取 / 多客户端同时操作不再出现寄存器读写交错
- 历史队列、批量任务、模拟器状态三处各自独立加锁，互不死锁

## 四、协议支持矩阵

> 详细的验证等级、交叉校验结果与已知边界见 [COMPATIBILITY.md](COMPATIBILITY.md)。
> Modbus 8 个功能码的 TCP/RTU 帧已与 pymodbus 标准实现逐字节交叉验证（17/17 通过）。

| 协议 | 帧结构 | 支持功能 | 默认端口 |
|---|---|---|---|
| Modbus TCP | MBAP + PDU | 01读线圈 02读离散 03读保持 04读输入 05写单圈 06写单寄存器 15写多圈 16写多寄存器 | 502 |
| Modbus RTU | 地址+PDU+CRC16 | 同上（CRC16 校验，低字节在前） | 网关透传 |
| 三菱 MC 3E | Qna 3E 二进制帧 | 0401读字 1401写字 0403读位 1403写位（D/M/X/Y/W/L/R） | 1031 |
| 欧姆龙 FINS/TCP | FINS/TCP + FINS 头 | 0101读DM/CIO 0102写DM/CIO（BCD 地址） | 9600 |
| AB Ethernet/IP | EIP封装+CPF+CIP | 0E读标签 10写标签 63识别设备 | 44818 |

### 报文示例

**Modbus TCP 读保持寄存器**（事务1，从站1，起始0，数量10）：
```
请求  00 01 00 00 00 06 01 03 00 00 00 0A
响应  00 01 00 00 00 17 01 03 14 [20字节数据]
```

**三菱 MC 读 D100 起 3 个字**：
```
请求  50 00 00 FF FF 0A 00 01 04 00 00 A8 64 00 00 03 00
响应  D0 00 00 FF FF 09 00 00 00 [3个字数据]
```

**欧姆龙 FINS 读 DM100 起 10 字**（BCD 地址 0100）：
```
请求  00 00 00 00 00 00 00 19 00 00 00 02 00 00 00 00
      80 00 02 00 01 00 00 00 00 00 01 01 82 01 00 00 0A
```

**AB Get Attribute**（读实例1）：
```
请求  6F 00 1C 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
      00 00 00 00 02 00 00 00 00 00 B1 00 08 0E 03 20 02 24 01 30 03
```

## 六、测试

```bat
python -m unittest discover -s tests -v
```
64 项测试全部通过：
- 协议单元（51 项）：CRC16 标准向量、五协议栈请求字节级构造、读写状态闭环、异常帧、位打包、BCD 编解码、从站扫描、串口参数校验、CSV/JSON 往返、字段解码、诊断助手、会话管理、并发隔离
- API 集成（13 项）：临时 HTTP 服务 + pymodbus 标准从站，覆盖 meta/op/history/export/import/session/scan/batch 全部端点，以及真机 TCP 读写、写后回读、断线重连、批量取消

帧级交叉校验另见 `verify/crosscheck_pymodbus.py`（17/17 与 pymodbus 标准帧逐字节一致）。集成测试需安装 pymodbus（仅测试环境，exe 不依赖）。

## 七、技术说明

- 协议栈自研（无 pymodbus/pymcprotocol 依赖），仅串口模式用 pyserial
- 模拟器从站按真实协议规范响应，可替换成真机验证同一套编解码逻辑
- HTTP 服务用 `ThreadingHTTPServer`，资源路径兼容源码与 PyInstaller 打包
- 报文历史线程安全，最多保留 200 条；扫描使用线程池并发探询

## 八、限制

- 串口直连仅支持 Modbus RTU（其他协议本身走 TCP）；需要本机有可用 COM 口
- AB 协议实现 UCMM 显式报文的 Get/Set Attribute，未实现隐式 I/O 消息与 Tag 符号解析的完整类型系统
- 模拟器为内存模型，不模拟真实设备的时序与工艺行为
